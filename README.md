# MedKit

MedKit is a browser-based clinical education application.

## Structure
- `index.html` — application markup
- `css/styles.css` — original inline styles extracted without redesign
- `js/app.js` — original inline JavaScript extracted without changing application logic

## Run locally
Open `index.html` in a modern browser. For best results, use a local web server (for example VS Code Live Server) because future PWA/API features may require HTTP/HTTPS.

## Notes
This refactor separates the original single-file application into maintainable files. No application logic, clinical content, or UI behaviour was intentionally changed.
